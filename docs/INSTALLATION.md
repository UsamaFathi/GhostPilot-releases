# GhostPilot installation information

GhostPilot by GhostForge has no production release available. This page describes
how to identify and verify a future approved download. Installation instructions
will be provided once an actual distribution package has been approved and tested.

When a release is available:

1. Open [GitHub Releases](https://github.com/UsamaFathi/GhostPilot-releases/releases)
   and choose the version you intend to install.
2. Check its release notes for supported environments, prerequisites, and the
   exact name of the approved installation file. GitHub's automatically generated
   repository archives are documentation snapshots.
3. Download the named file and its checksum manifest from that release. Compute
   the file's SHA-256 digest and compare it with the entry for that exact filename.
   If they differ, stop before installing.
4. Follow the tested installation and verification steps for that version.

See the [release policy](../RELEASE_POLICY.md) and return to the
[GhostPilot overview](../README.md).
