# GhostPilot

**GhostPilot by GhostForge** is an Odoo Engineering Intelligence Platform designed to help
developers inspect addon source, understand dependencies and model relationships, and
review changes using static analysis.

GhostPilot is **proprietary, closed-source freeware**. It is free to download and
use for personal, professional, commercial, enterprise, educational, and research
purposes. There are no subscriptions, paid licenses, paid activation, license keys,
or usage fees.

The development source remains private. Permission to redistribute or modify
GhostPilot requires separately approved proprietary licensing terms.

**No production release is available yet.** Future approved downloads, release notes,
SHA-256 checksums, and supported environments will appear on the
[GitHub Releases page](https://github.com/UsamaFathi/GhostPilot-releases/releases).
