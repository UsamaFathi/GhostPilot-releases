# GhostPilot security reporting

GhostForge is the publisher of GhostPilot. No production release is available yet,
and there are currently no supported production versions.

A private security reporting process is pending. GhostForge will update this page
once a reporting channel is approved and available.

Keep suspected vulnerabilities and supporting material private. Do not post
credentials, project source, diagnostic reports, or sensitive reproduction details
in public issues, discussions, or pull requests.

See the [release policy](RELEASE_POLICY.md) for how future versions will be published.
