# GhostPilot release policy

GhostForge is the publisher of GhostPilot. No production release is available yet.

Future approved versions will be published on
[GitHub Releases](https://github.com/UsamaFathi/GhostPilot-releases/releases). Each release
will identify its version, approved downloads, supported environments, known limitations,
installation instructions, SHA-256 checksums, and applicable terms and third-party notices.

GhostForge will publish a version after reviewing the release contents, completing
installation checks for the advertised environments, verifying artifact digests, and
approving distribution. Release notes will distinguish any preview from a production
release and describe its support status.

Corrections to published artifacts will use a new version. If a version is withdrawn, its
release notes will identify the withdrawal and point to a replacement when one is available.

See [installation information](docs/INSTALLATION.md) and the [changelog](CHANGELOG.md).
